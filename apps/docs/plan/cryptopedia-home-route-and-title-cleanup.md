# 생태계 홈 주소·제목 라벨 정리

2026-10-16 사용자 요청: 모든 페이지 제목 위의 영어 라벨을 제거하고 `/`와 `/about`의 중복을 정리한다.

## 확인된 현재 구조

- `/`는 `EcosystemPage`, `/about`은 `EcosystemHomeV2`를 같은 `EditorialApp` 안에 렌더링한다.
- 로고는 `/about`으로 이동하고, 메뉴의 생태계 홈은 `/`로 이동한다.
- 나머지 편집 페이지는 `EditorialApp`의 화면 상태로 전환되므로 URL·새로고침·브라우저 뒤로가기가 페이지 상태를 표현하지 않는다.

## 이번 변경 범위

1. 페이지와 홈 주요 섹션의 제목 위 영문 `eyebrow`를 화면에서 제거한다. 제목·설명·본문의 의미 있는 영어 고유명사는 유지한다.
2. 두 화면을 각각 유지한다. 로고 클릭은 `/about`, 생태계 홈 메뉴 클릭은 `/`로 이동한다.
3. 생태계·챕터의 주요 화면과 상세 화면에 URL을 부여한다. 메뉴·브레드크럼 이동은 해당 URL로 이동한다. 기존 셸과 데이터 조회 컴포넌트는 재사용한다.
4. 각 주요 화면에 Next.js 라우트 파일을 두고, 기사·책은 동적 상세 라우트로 묶는다. 공통 레이아웃에서 선택한 체인을 유지한다.

## 판단과 확인

- 생태계 백과사전은 공유 링크·새로고침·뒤로가기·검색 노출이 중요하므로 주요 화면과 상세 화면을 실제 URL로 분리하는 편이 좋다.
- 실제 URL이 있어야 화면을 새로고침·직접 링크·브라우저 뒤로가기로 다시 열 수 있다. 주요 화면의 라우트 파일이 화면 종류와 제목·설명 메타데이터를 지정한다. `EditorialApp`은 공통 셸·데이터 로더·기존 화면 컴포넌트 연결을 맡는다. 서버 렌더링 데이터 및 체인별 공개 URL은 후속 작업이다.
- 제목 라벨 잔여, 두 홈의 직접 진입과 로고·메뉴 이동, 상세 화면 직접 진입·뒤로가기를 확인한다.

## 적용된 경로

| 화면                               | URL                                                                                  |
| ---------------------------------- | ------------------------------------------------------------------------------------ |
| 생태계 홈(메뉴)                    | `/`                                                                                  |
| About(로고)                        | `/about`                                                                             |
| 컬렉션 선택                        | `/chains`                                                                            |
| 프로젝트·매크로·행사·업데이트      | `/ecosystem/projects`, `/ecosystem/macro`, `/ecosystem/events`, `/ecosystem/updates` |
| 지난 행사·빌더 유형 테스트         | `/ecosystem/events/archive`, `/ecosystem/builder-test`                               |
| 체인 기초·빌더 라이브러리·아카데미 | `/chapters/fundamentals`, `/chapters/builders`, `/chapters/academy`                  |
| 상세 자료                          | 각 부모 경로 뒤에 자료 ID, 책은 `/ecosystem/projects/books/:id`                      |

URL은 화면 이동과 새로고침에서 현재 페이지를 복원한다. 모든 주요 화면은 `apps/web/app/(cryptopedia)/` 아래에 별도 `page.tsx`가 있다. 기사·책 상세는 각각 `chapters/[section]/[id]`, `ecosystem/[section]/[id]`, `ecosystem/articles/[id]`, `ecosystem/projects/books/[id]`에서 받는다. 공통 `layout.tsx`가 선택 체인 상태를 유지한다. 단일 catch-all 페이지는 제거했다. 각 라우트에 제목·설명 메타데이터를 넣었고, 상세 자료는 큐레이션 JSON의 제목·설명을 이용한다. 실제 페이지별 서버 데이터 로딩·체인별 공개 URL은 후속 작업이다.

## 확인 결과

- 경로 해석 및 편집 화면 렌더 관련 65개 검사 통과.
- 개발 서버에서 `/`와 `/about` 모두 200 확인. Chrome에서 `/`는 기존 `Buzz Distribution`, `/about`은 새 홈의 빌더 테스트를 표시하는 것을 확인. 로고 클릭은 `/about`, 생태계 홈 메뉴 클릭은 `/`로 이동한다.
- 주요·상세 경로의 직접 진입과 알 수 없는 경로 404, 매크로 메뉴 이동·새로고침·뒤로가기는 앞선 경로 정리 검사에서 확인했다.
- 라우트 분리 후 개발 서버에서 두 홈·컬렉션·생태계·챕터·상세 16개 주소 200, 미지원 주소 3개 404 확인. Chrome에서 메뉴 이동·새로고침·뒤로가기, 로고와 생태계 홈 메뉴가 각각 다른 홈을 여는 동작을 재확인했다.
- 전체 웹 타입 검사에서 이번 변경 오류는 없고, 기존 KaaS 컴포넌트 오류 8개가 남아 있다.

## 2026-10-16 — About 상단 콘텐츠를 생태계 홈으로 이동

- `/about`의 체인 타이틀·소개·키워드·빌더 유형 테스트 배너를 `/` 생태계 홈의 뉴스 슬라이드 앞에 옮겼다. 기존 홈의 중복 타이틀은 제거하고 공식 홈페이지 링크는 새 상단 영역에 유지했다.
- `/about`은 만들 수 있는 것·생태계 소식·학습 시작하기로 이어진다. 페이지 제목 메타데이터도 About에 맞췄다.
- 렌더 검사와 브라우저에서 순서, CTA의 `/ecosystem/builder-test` 이동, `/about`의 배너 제거를 확인했다.

## 2026-10-16 — 생태계 홈 인라인 빌더 설문

- 생태계 홈의 빌더 유형 테스트 배너를 직접 답할 수 있는 설문 카드로 교체했다. 데스크톱에서는 기존 소식 `HeroCarousel`을 왼쪽, 4문항 설문을 오른쪽에 두고 모바일에서는 위아래로 배치한다.
- 전용 테스트 화면의 질문 진행·동점 선택·결과 판정 로직을 그대로 사용한다. 홈의 결과 카드에서는 유형 설명과 추천 탐색 경로, 다시 테스트하기를 보여 준다. `/ecosystem/builder-test` 직접 경로도 유지한다.
- 브라우저에서 데스크톱 좌우 정렬, 모바일 순서, 4문항 완료·결과·재시작을 확인했다.
