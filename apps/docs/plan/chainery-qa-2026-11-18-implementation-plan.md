# Chainery QA 수정 계획 (2026-11-18)

## 기준과 범위

- 기준: 원격 `deploy`의 `8e00606`.
- 사용자에게 보이는 `Cryptopedia` 표기를 `Chainery`로 바꾼다. 코드 식별자, 공개 정적 경로, 브라우저 저장 키는 변경하지 않는다.
- `/my-path`와 홈의 다음 할 것 카드에서 중복 단계 번호를 제거한다.
- 현재 경로의 첫 미완료 단계와 일치하는 LIVE 화면 또는 스킬 상세에 완료 버튼을 표시하고 기존 학습자 기록에 저장한다. 개념의 기존 완료 버튼과 실습 체크리스트는 재사용한다.
- `/academy/skill-graph`의 지도 노드 클릭은 해당 설명 영역으로 이동한다.
- AdSense 연결은 별도 후속 작업으로 둔다. `/events`는 준비 중이다.

## 구현 순서

1. 화면 문구, 접근성 문구, 정적 콘텐츠 및 다운로드 문구의 브랜드명을 교체한다.
2. 학습 경로 카드의 중복 번호를 제거하고, 현재 단계와 화면의 종류·ID·체인이 일치할 때만 떠 있는 완료 버튼을 표시한다.
3. 지도 노드 클릭에 설명 영역 스크롤을 연결하고 동작 줄이기 설정을 따른다.
4. 관련 테스트와 타입 검사를 실행하고 변경 범위만 검토해 커밋한다.
