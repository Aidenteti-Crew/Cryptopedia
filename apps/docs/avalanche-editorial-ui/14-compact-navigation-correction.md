# 탐색 밀도와 목록 표현 수정

- 요청: 릴리스 이력을 전체/Coreth/Subnet-EVM 제품 탭으로 탐색하고 상단 높이를 줄인다.
- 개발 업데이트: 보기 전환과 검색을 같은 줄, 다음 줄에 제품 또는 콘텐츠 유형 탭과 필터. 제품 전체는 모든 릴리스를 공개일 순으로 표시한다.
- 목록: 프로젝트 리스트/뉴스/행사/개발 목록은 투명 배경과 얇은 하단 구분선. 프로젝트 카드 보기는 명시적으로 선택한 별도 보기로 유지한다.
- 검증: 전체/개별 제품 전환, 검색 유지, 릴리스 단계 필터, 모바일 넘침, 기존 회귀 테스트와 실제 화면 확인.
