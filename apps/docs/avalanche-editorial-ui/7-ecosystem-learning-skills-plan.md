# 체인 생태계·학습·에이전트 스킬 데모 구현 계획

## 승인된 범위

2026-10-10 대화에서 확정한 목차와 재사용 방향을 구현한다. 현재 에디토리얼 셸과 모바일 여백을 유지하며, 결제·마켓·Arena·성능 비교는 제외한다. API·DB·기존 `/start/*` 흐름은 변경하지 않는다.

## 구현 순서

1. 출처와 적용 범위를 구분하는 정적 데이터 계약: 공식·표준·커뮤니티·큐레이션 출처, 공통/EVM/체인 범위, 프로젝트·개념·케이스·스킬·변경의 ID 연결. 체인별 조회는 선택 체인과 적용 가능한 공통 자료를 포함한다.
2. 확정 목차 반영. 생태계 지도는 기존 LandscapeGrid, 학습 지도는 기존 ConceptRoadmap, 개발 업데이트는 기존 Patch Notes 항목 표시를 재사용한다. 기존 화면은 기본 동작을 보존하고 선택적 표시 확장만 추가한다.
3. 케이스별 실습과 스킬 라이브러리: 기존 Workshop의 스킬 종류와 묶음 구성 흐름을 단순화해 학습 단계·완료 체크리스트·선택 스킬·다운로드를 연결한다. 실설치 성공을 모사하지 않고 실제 파일 다운로드 결과를 표시한다.
4. 생태계 홈에서 프로젝트·케이스·스킬·업데이트를 직접 연결. 정적 데모 상태와 실제 공식 자료 링크를 구분한다.
5. 데이터 스키마·참조 무결성·체인 범위 필터·다운로드·화면 이동·회귀 테스트, 타입 검사, 가능한 브라우저 관측과 인수인계 기록.

## 설계 판단

- 좁은 범위: Avalanche의 대표 실습 3개를 정적 데이터로 연결하며 수집·자동 영향 분석·원격 설치는 후속이다.
- 단순성: 기존 상태 기반 라우팅과 저장소 계약을 유지한다. 동일 자료를 복제하지 않고 ID로 연결한다.
- 가시성: Demo 표시, 공식 출처 링크, 영향받는 자료의 직접 이동, 다운로드 가능한 작업 지침을 제공한다.

## 검토

- 논리: 라이브러리는 자료 원본, 아카데미는 자료를 활용하는 순서이며 새 대분류를 추가하지 않는다.
- 실패 경로: 비활성 체인 선택 차단, 없는 참조는 데이터 검증에서 거절, 범위 밖 자료는 숨김, 선택 스킬이 없으면 다운로드 차단, 로딩·오류·빈 결과 표시.
- 통합: 기존 `/start/*`·API·DB와 별개의 정적 공급자 사용. 기존 공용 컴포넌트의 확장은 기본값을 보존한다.
- 열린 검토: 에이전트 전달을 실제 설치로 오인할 수 있어 다운로드와 연결 설정 안내까지만 제공하며, 적용 환경과 확인 항목을 묶음에 포함한다.

## 완료 기준

현재 목차에서 생태계 탐색 → 케이스 학습 → 스킬 다운로드 → 변경 영향 확인 흐름을 수행할 수 있다. 공식 자료와 범용 자료를 함께 보여주며 기존 UI의 구조를 재사용한다.
