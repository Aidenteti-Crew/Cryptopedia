# 페이지 전환 모션 설계

## 목표

에디토리얼 레이아웃의 헤더와 내비게이션은 고정하고, 읽기 콘텐츠만 짧게 전환해 페이지 이동의 맥락을 부드럽게 연결한다.

## 동작

- 최초 진입에서는 애니메이션을 재생하지 않는다.
- 화면 식별자가 바뀔 때 기존 콘텐츠는 120ms 동안 위로 4px 이동하며 사라진다.
- 새 콘텐츠는 180ms 동안 아래 6px에서 제자리로 이동하며 나타난다.
- 전환은 `cubic-bezier(0.2, 0, 0, 1)` 감속 곡선을 사용한다.
- `prefers-reduced-motion` 사용자는 이동 없이 즉시 교체한다.
- 레이아웃 크기, 데이터 요청, URL 및 내비게이션 상태는 변경하지 않는다.

## 검증

- 모든 화면 종류가 서로 다른 전환 키를 갖는지 자동 테스트한다.
- 첫 렌더 제외와 축소 모션 처리를 자동 테스트한다.
- 실제 브라우저에서 목록, 상세, 뒤로 가기, 연속 클릭을 확인한다.
