# 달력 오른쪽의 전체 내용과 페이지 스크롤

- 행사/매크로 카드의 요약 줄 제한을 제거하고 내용 길이대로 높이를 사용한다. 긴 제목/URL은 카드 너비에서 줄바꿈한다.
- 개발 업데이트의 상단 이동/복귀 로직을 `use-reading-scroll.ts`로 공유해 달력 오른쪽에서도 동일하게 동작시킨다.
- 읽기 목록의 높이는 스크롤 중 변경하지 않으며, 화면보다 커져 끝을 읽지 못하지 않도록 최대 높이를 화면 높이−48px로 제한한다.
- 달력 날짜 선택과 목록→월 이동, 검색/필터, 원문 링크를 보존한다.
- 검증: 실제 긴 글의 표시 높이/잘림 여부, 상단 이동/복귀, 일정 날짜 연동, 기존 회귀 테스트.

## 검증 결과

- 관련 테스트 21개 통과, 변경 파일 ESLint 및 diff 검사 통과.
- 실제 매크로 카드 높이 313/265/289/313px로 내용 길이에 따라 표시. 요약의 clientHeight=scrollHeight(120/72/96/120px), line-clamp=none 확인.
- 매크로 오른쪽 입력: 상단 page=370px 이동/읽기 영역 top=23.5px, 이후 목록 240px 스크롤. 위 방향 입력 시 page=0으로 복귀하면서 목록 240px 유지.
- 행사 오른쪽 입력: page=381px/읽기 영역 top=23.5px. 10월 17일 선택 연동 확인. 가로 넘침/브라우저 오류 없음.
- 검증 브랜치 `verify/deploy-latest`, 로컬 :3002에 반영. 커밋/원격 푸시 없음.
