# 생태계 홈 — Cherry Overview UI 재사용

기준일: 2026-10-14. 사용자 요청으로 생태계 홈부터 변경한다. 기존 `nd-overview-page.tsx`의 히어로 슬라이드·좌우 분할 그라디언트·스포트라이트 카드 구성을 최대한 재사용하고 현재 네비게이션과 breadcrumb는 유지한다.

## 구현

1. 기존 HeroCarousel을 내보내고 내부 페이지 이동과 반응형 표시를 위한 선택적 슬라이드 렌더링을 추가한다. 자동 순환·스와이프·방향 버튼·인디케이터를 유지하며 이동 거리와 화면 크기 변경을 확인한다.
2. 생태계 홈의 가장 상단에 체인·프로젝트, 매크로, 행사·이벤트, 개발 소식을 배치한다. 현재는 정적 예시 콘텐츠임을 표시하며 실제 최신 발표라고 주장하지 않는다.
3. 기존 Overview의 두 스포트라이트 카드 구성을 응용해 ‘사람이 공부하기’는 케이스별 실습, ‘에이전트에게 전달하기’는 스킬 라이브러리로 이동시킨다. 학습은 지식·지침 제공이며 모델 훈련이나 원격 설치 성공으로 표현하지 않는다.
4. 하단의 추천 케이스와 생태계 탐색 링크는 같은 카드·목록 위계로 정리한다. Buzz Distribution 포함 여부는 사용자 선호를 확인한다.

## Buzz Distribution의 의미

기존 백엔드 `landing-stat.service.ts`는 최근 7일의 수집 기사 수를 분야별로 집계하고 분야 건수를 전체 분야 건수 합계로 나누어 비율을 만든다. `CategoryTreemap`이 비율에 따라 사각형 면적을 표시한다. 조회수·시장 인기도를 뜻하지 않는다. 데이터가 없으면 기존 컴포넌트가 AI 분야 예시로 대체하므로 블록체인 홈에서 그 기본 폴백을 사용하지 않는다.
