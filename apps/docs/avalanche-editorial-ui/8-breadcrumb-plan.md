# 공통 breadcrumb 구현

- 사용자 요청: 모든 페이지 왼쪽 상단에서 목록으로 돌아가기 버튼을 제거하고, 현재 위치와 상위 페이지 이동을 제공한다.
- 현재 상태: 상세 페이지마다 돌아가기 버튼이 있고 일부 목록의 경로 표시는 문자열이라 이동할 수 없다.
- 구현: 공통 셸에 breadcrumb를 한 번만 표시한다. 현재 목차의 `ECOSYSTEM` 또는 `CHAPTERS`부터 시작하고 마지막 항목은 현재 페이지, 상위 페이지는 이동 버튼으로 표시한다. 그룹명은 별도 페이지가 없는 분류 표시다. 케이스·스킬·개념·자료 상세는 각각 해당 라이브러리/목록을 포함한다. 이벤트 아카이브는 행사·이벤트 아래로 연결한다.
- 범위: `/` 에디토리얼 앱의 전체 페이지·로딩·오류 상태. 별도 `/start/*` 앱의 네비게이션은 유지한다.
- 검토: 탐색 이력이 아니라 콘텐츠의 정해진 위치를 사용해 같은 자료가 어디에서 열려도 같은 경로를 표시한다. 제목을 못 불러와도 상위 페이지 이동은 유지한다. 긴 경로는 모바일에서 줄바꿈하며 현재 항목은 클릭할 수 없다.

| 검수 | 상태 | 기준 |
|---|---|---|
| 모든 화면 공통 경로 | ✅ | 공통 셸에 1개만 렌더링, 홈·주요 메뉴·상세 경로 검증 |
| 상위 메뉴·목록 이동 | ✅ | 케이스·스킬·개념·자료·프로젝트·변경·아카이브 경로와 실제 클릭 이동 확인 |
| 돌아가기·중복 경로 제거 | ✅ | 기존 버튼과 정적 경로 문자열 제거, 소스 검색과 브라우저 확인 |
| 모바일·키보드 접근 | ✅ | Chrome 1440/834/390에서 긴 경로 줄바꿈·가로 넘침 없음, Enter로 상위 이동 확인 |
| 회귀·타입 검사 | ✅ | 관련 테스트 64개 통과. 타입 검사는 기존 KaaS 오류 8개만 발생 |

## 결과와 증빙

- 공통 `editorial-breadcrumb.tsx`에서 목차와 콘텐츠 종류를 기준으로 경로를 생성한다. 탐색 이력과 무관하며 현재 항목은 `aria-current="page"`, 상위 항목은 이동 버튼이다.
- 모든 실제 페이지와 로딩·오류 상태의 상단에 표시하고 모바일 좌우 16px 정렬을 유지한다. 각 본문의 중복 상단 여백을 정리했다.
- 기존 상세 돌아가기 콜백과 앱의 탐색 이력 저장은 제거했다. 공개 reducer의 기존 동작은 보존했다.
- `/private/tmp/cryptopedia-breadcrumb-browser-result.json`: 경로·상위 이동·키보드·중복 없음·돌아가기 버튼 없음·pageerror 0.
- `/private/tmp/cryptopedia-breadcrumb-1440.png`, `/private/tmp/cryptopedia-breadcrumb-834.png`, `/private/tmp/cryptopedia-breadcrumb-390.png`.

## 메뉴 그룹 기준 경로 보정

- 사용자 요청으로 공통 생태계 홈 시작점을 제거하고 사이드바 그룹과 일치시켰다.
- 예: `ECOSYSTEM → 생태계 홈 → 개발 업데이트 → 변경 상세`, `CHAPTERS → 아카데미 → 케이스별 실습 → 케이스 상세`.
- 생태계 홈 자체는 `ECOSYSTEM → 생태계 홈`. 그룹 표시에는 이동 버튼을 만들지 않으며 그 아래 실제 메뉴·목록의 이동은 유지한다.
- 관련 테스트 64개 통과, 1440/834/390 브라우저에서 그룹별 경로·상위 이동·줄바꿈 확인.

### 생태계 홈 계층과 화살표 정렬 보정

- 생태계 메뉴는 실제 사이드바 계층처럼 `ECOSYSTEM → 생태계 홈 → 체인·프로젝트`로 표시하고 홈 항목을 이동 버튼으로 제공한다. CHAPTERS에는 생태계 홈을 넣지 않는다.
- 화살표의 고정 상단 여백을 제거하고 항목을 수직 중앙 정렬해 텍스트와 높이를 맞췄다.
- 테스트 64개 통과. Chrome 1440/834/390에서 경로와 상위 이동을 확인하고 화살표·텍스트의 중심 높이 차이가 1px 미만임을 검증.
