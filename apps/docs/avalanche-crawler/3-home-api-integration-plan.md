# 생태계 홈 API 연결

사용자 승인: 생태계 홈 연결 진행.

- 기존 레이아웃과 사용자가 숨긴 섹션 유지.
- 매크로 최신 4건, 개발 최신 4건, 예정 행사 4건을 실제 API에서 조회.
- 프로젝트 디렉터리는 뉴스로 오인하지 않도록 제외.
- 슬라이드 원문 링크 연결, 행사 일정과 게시일 구별.
- Buzz는 표시된 자료의 분포이며 시장 인기도나 전체/주간 통계가 아님.
- 학습 경로는 기존 정적 자료 유지. 실패 시 가짜 소식으로 대체하지 않음.
- 어댑터 테스트, 실제 API 계약, 브라우저 및 타입 검사. 배포 제외.

## 완료 및 검증

- 실제 로컬 API에서 매크로 4건, 업데이트 4건, 예정 행사 2건 표시.
- 외부 원문은 새 탭에서 열림. 행사 날짜는 게시일과 구분.
- 사람/에이전트 카드는 기존 내부 학습 경로 유지.
- 관련 테스트 72개 통과. 실제 API 계약 검사 통과.
- Chrome 데스크톱/390px 모바일 확인: 가로 넘침 없음.
- API 503 주입 시 다시 시도 표시, 복구 후 재조회 성공.
- 전체 타입 검사: 기존 KaaS 오류 8개, 이번 변경 관련 오류 없음.
- 다른 분야별 페이지는 아직 정적 데이터. 배포/자동 스케줄링은 수행하지 않음.
